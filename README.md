# Онлайн «Крестики-нолики» (Go Backend)

Бэкенд-сервис для игры в «крестики-нолики» в реальном времени с разделением на слои (Clean Architecture) и аутентификацией на базе асимметричных JWT.

## Стек технологий

* **Язык:** Go
* **Архитектура & DI:** Clean Architecture, Uber FX
* **База данных:** PostgreSQL (`pgx`)
* **Сеть & Транспорт:** REST API
* **Безопасность:** JWT (RSA-2048)
* **Инфраструктура:** Docker, Docker Compose

---

## Особенности реализации

* Игровая логика и управление игровыми сессиями через REST API.
* Внедрение зависимостей через `go.uber.org/fx`.
* Чистая архитектура с изоляцией бизнес-логики от БД и транспорта.
* Директория `web/` содержит базовый интерфейс исключительно для наглядной демонстрации работы API.
* Полная документация по API в api.md (в корне проекта)

## Быстрый старт

```bash
docker compose -f deploy/docker-compose.yaml up -d --build
```
- Приложение будет доступно на `http://localhost:80`
